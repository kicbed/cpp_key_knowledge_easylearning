# C++ Key Knowledge Easy Learning

这是一套面向 C++ 后端 / Linux C++ / 基础软件面试的学习资料，重点是“讲清楚、方便学”，不是只给简短八股答案。

- [电脑统一详解版](./01_统一详解版/电脑统一详解版.html)
- [手机统一详解版](./02_手机学习/手机统一详解版.html)

## 内容结构

- `01_统一详解版`：297 题全量详解，包含人话理解、原理拆解、代码/伪代码示例、底层原理、面试回答和追问。
- `02_手机学习`：手机 HTML 和 AnkiDroid 导入卡片。
- `03_代码示例`：C++ 手撕代码、工程代码示例、代码专题讲解。
- `04_模拟面试`：项目追问链和 45 分钟模拟面试脚本。
- `05_来源索引`：参考来源、筛选规则、去重规则。

## 使用建议

先看 `00_使用总纲.md`，再按模块学习统一详解版。手机端适合随机抽题和碎片复习，电脑端适合系统阅读和搜索。
