# 手机使用说明

优先打开：

`手机统一详解版.html`

这是唯一手机版主入口，包含 297 张统一详解卡片。每张卡片包含：

- 这题在考什么
- 先用人话理解
- 原理拆开
- 代码/伪代码示例
- 底层原理再往下一层
- 面试回答版
- 易错点
- 面试官可能继续追问

## 功能

- 搜索：直接搜 `shared_ptr`、`epoll`、`MVCC`、`线程池` 等关键词。
- 标签筛选：按 C++、STL、并发、网络、数据库、Redis/MQ、项目、代码等模块看。
- 随机抽题：适合碎片时间。
- 显示/隐藏答案：先自己讲，再看答案。
- 已掌握：进度保存在本机浏览器。

## 传到手机

任选一种：

1. 把整个 `D:\AI_CPP_Interview_Study` 文件夹同步到网盘。
2. 单独把 `02_手机学习\手机统一详解版.html` 发到手机。
3. 使用 AnkiDroid 时，导入 `AnkiDroid_统一详解卡片.tsv`。

## AnkiDroid 导入

`AnkiDroid_统一详解卡片.tsv` 是三列：

1. 正面：问题
2. 背面：详解答案
3. 标签：模块

导入时字段分隔符选择 Tab。
