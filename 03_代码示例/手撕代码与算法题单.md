## 2. C++ 后端更容易手撕的工程题

### 2.1 LRU Cache

**回答主线：**

LRU 要同时满足查找 O(1)、更新最近使用 O(1)、淘汰最久未使用 O(1)。哈希表负责 key 到链表节点的定位；双向链表负责维护新旧顺序。访问或更新一个 key 时，把节点移动到链表头；容量满时删除链表尾。

**易错点：**

- `put` 已存在 key 时要更新值并移动到头部。
- 容量为 0 要单独处理。
- 手写链表时注意删除节点前后指针；用 `std::list` 可以降低出错率。

### 2.2 线程安全阻塞队列

**回答主线：**

用 `std::queue` 保存任务，`std::mutex` 保护队列，`std::condition_variable` 在队列空时阻塞消费者。等待时必须使用 predicate 或 while，防止虚假唤醒。停止时设置 `closed` 并 `notify_all`。

**易错点：**

- 不要在没加锁时访问队列。
- `close()` 后生产者是否还能 push，要定义清楚。
- 消费者被唤醒后要同时判断“有数据”或“已关闭”。

### 2.3 线程池

**回答主线：**

固定数量 worker 线程从阻塞队列取任务执行。`submit` 把任务入队并唤醒一个 worker。析构时设置停止标志，唤醒所有 worker，然后 join。支持返回值可以用 `std::packaged_task` + `std::future`。

**易错点：**

- worker 线程函数要捕获 `this`，但析构时必须保证线程退出后对象才销毁。
- 任务抛异常不能让 worker 线程直接崩掉。
- 队列无限增长会造成内存问题，工程版要做容量和背压。

### 2.4 单例模式

**推荐写法：**

C++11 起函数局部静态变量初始化线程安全，Meyers Singleton 简洁可靠。

```cpp
class Singleton {
public:
    static Singleton& instance() {
        static Singleton obj;
        return obj;
    }
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
private:
    Singleton() = default;
};
```

**易错点：**

双重检查锁如果没有正确的内存序，历史上容易出错。面试中优先讲局部静态变量版本。

### 2.5 生产者消费者

**回答主线：**

有界队列需要两个条件变量：`not_empty` 给消费者等数据，`not_full` 给生产者等空间。生产者 push 后通知 not_empty；消费者 pop 后通知 not_full。

**易错点：**

等待条件要写成 `while (queue full)` 和 `while (queue empty)`，不能用 `if`。

## 3. 高频算法模板

### 3.1 滑动窗口

适用：最长/最短连续子数组或子串，窗口内满足某种约束。

模板：

```cpp
int left = 0;
for (int right = 0; right < n; ++right) {
    add(a[right]);
    while (bad()) {
        remove(a[left]);
        ++left;
    }
    update_answer(left, right);
}
```

### 3.2 二分查找

适用：有序数组、答案具有单调性。

关键：先定义搜索区间和循环不变量。不要凭感觉改边界。

```cpp
int l = 0, r = n; // [l, r)
while (l < r) {
    int mid = l + (r - l) / 2;
    if (check(mid)) r = mid;
    else l = mid + 1;
}
```

### 3.3 单调栈

适用：下一个更大/更小元素、柱状图面积、每日温度。

核心：栈里维护还没找到答案的下标，且对应值单调。

### 3.4 BFS

适用：最短步数、层序遍历、无权图最短路。

关键：入队时标记 visited，避免重复入队。

### 3.5 DFS 回溯

适用：排列、组合、子集、棋盘搜索。

关键：选择、递归、撤销选择；剪枝要基于明确条件。

### 3.6 动态规划

回答步骤：

1. 定义状态。
2. 写状态转移。
3. 明确初始化。
4. 明确遍历顺序。
5. 说明复杂度和能否压缩空间。

## 4. 经典题的面试讲法

### 4.1 快排

**讲法：**

选 pivot，把数组划分为小于 pivot 和大于 pivot 的两部分，然后递归排序两边。平均 O(n log n)，最坏 O(n^2)。避免最坏情况可随机选 pivot 或三数取中。小数组可切换插入排序。

### 4.2 归并排序

**讲法：**

分治排序，先递归排序左右两半，再线性合并两个有序数组。时间稳定 O(n log n)，需要 O(n) 额外空间，天然稳定，适合链表排序和外部排序思想。

### 4.3 堆排序

**讲法：**

先建大根堆，再不断把堆顶最大值交换到数组末尾并下沉调整。时间 O(n log n)，额外空间 O(1)，不稳定。

### 4.4 TopK

**讲法：**

小 K 用大小为 K 的小根堆，遍历元素，大于堆顶则替换，复杂度 O(n log k)。如果允许改变数组且追求平均 O(n)，可以用快速选择。

### 4.5 LRU

**讲法：**

哈希表加双向链表。每次访问移动到头部，容量满淘汰尾部。哈希表保证定位 O(1)，链表保证移动和删除 O(1)。

## 6. 面试时手撕代码的检查清单

- 函数签名是否和题目一致。
- 空输入、单元素、重复元素是否处理。
- 指针更新是否会丢节点。
- 循环边界是否会越界。
- 复杂度是否能说清楚。
- C++ 资源是否 RAII，是否有裸 `new/delete` 泄漏。
- 并发题是否考虑虚假唤醒、停止条件、异常。
